# AI-videos — skill de Claude para videos con IA

Playbook para crear imágenes y videos con IA: flujo imagen-primero, qué modelo usar, fórmulas de prompt, continuidad de personajes, edición, viralidad y anuncios.

## Instalar

**Claude.ai / app de escritorio:** Configuración → Capacidades → Skills → "Subir skill" → elige `aivideo.zip` (descárgalo de este repo).

**Claude Code:** copia la carpeta `aivideo` a `~/.claude/skills/` (en Windows: `C:\Users\TU_USUARIO\.claude\skills\`).

Luego pídele a Claude, por ejemplo: "usa el skill aivideo para hacer un video de 15 segundos sobre…".

Basado en lo aprendido en el curso AI Video Bootcamp (Skool), resumido con palabras propias. Los modelos y precios cambian rápido: verifica antes de comprar créditos.
